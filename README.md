# Pump Track Biking and Ski Jumping as Tutorial Problems for Nonsmooth Optimal Control


Matlab implementations using CasADi and nosnoc. Related paper: DOI: 10.1109/LCSYS.2024.3521556


## Installation
Requires CasADi and nosnoc in Matlab path
Versions used in publication: casadi-v3.5.5, nosnoc_v0.5.0

1. Get CasADi: https://web.casadi.org/get/

2. Get nosnoc: https://github.com/nurkanovic/nosnoc

3. `addpath('yourpath')`
